## ⚙ Использование
1. Скачайте zip архив со [страницы релизов](https://github.com/GBKSH/word-editor-for-project-open/releases/latest)
2. Найдите архив в загрузках вашего пк и распакуйте его в нужную папку
3. Запустите `ProjectEditor`
   > Помимо программы, архив содержит папку с дубликатом данной инструкции и мануалами для ручной доработки  
   > При желании эту папку можно удалить
4. Выберите файл для редактирования
5. Отметьте нужные вам доп. функции и начинайте обработку
## 🤔 Что редактирует?
- Поля: 2 см везде (нижнее, верхнее, левое, правое)
- Отдельно редактирует заголовки:
    - Выравнивает по центру
    - Меняет стиль шрифта ("TimesNewRoman") и его размер(14) 
    - Делает его жирным
    - Удаляет интервал перед и после абзаца (0 пт каждый)
    - Удаляет точки после абзаца (если автор проекта их напечатал)
    - Удаляет отступ слева и справа, отступ первой строки (0 см каждый)
    - Настраивает междустрочный интервал (1.5)
    - Назначает черный цвет
- Отдельно редактирует основной текст:
    - Выравнивает по ширине
    - Меняет стиль шрифта ("TimesNewRoman") и его размер(14) 
    - Удаляет отступ слева и справа (0 см каждый)
    - Назначает отступ первой строки (1,25 см)
    - Удаляет интервал перед и после абзаца (0 пт каждый)
    - Назначает междустрочный интервал (1.5)
    - Назначает черный цвет
- Добавляет шаблон титульного листа, с правильно выставленными пустыми строками и форматированием  
❗ Полезно использовать доп параметр "Титульный лист", чтобы не переделывать титул самому, т.к. при форматировании прежний будет отформатирован как основной текст.
## ✨ Мануалы для ручной доработки
Из-за отсутствия реализации некоторых функций, ниже предоставлены инструкции для ручного форматирования и доработки до идеала. Постарался написать их более подробно и понятно.
### Нумерация страниц
#### Для включения номеров страниц:
1. Перейдите на вкладку "Вставка" ->
2. Колонтитулы ->
3. Номер страницы ->
4. Выберите "внизу страницы". Нужен вариант с номером в нижнем правом углу
#### Чтобы убрать нумерацию на первой странице:
1. Перейдите в "конструктор"
2. Поставьте галочку в пункте "Особый колонтитул для первой страницы"
Номер на первой странице должен пропасть. После, ничего менять не надо. Можно закрывать конструктор (в углу "Закрыть окно колонтитулов").
 > Если вкладки "Конструктор" нет, то щелкните два раза левой кнопкой мыши в нижней части любой страницы. Конструктор должен открыться. Далее все по пунктам выше.
### Оглавление
1. Нужно присвоить каждому заголовку уровень:
- Выделите заголовок и нажми по нему правой кнопкой мыши
- Нажмите "абзац"
- В строке "уровень" выберите нужный уровень
 > Памятка:
 > - 1 уровень: введение, глава 1 с её названием, глава 2 с её названием, заключение, список используемых источников, приложение.
 > - подглавы: когда пишите проект, каждая подглава нумеруется и будет следующим уровнем, т.е., к примеру, 1.1 и 1.2 будут 2 уровня, 1.1.1 и 1.1.2 - 3 уровня и т.д.
2. Выберите куда нужно вставить оглавление (просто щелкните мышкой чтобы стик появился на нужной пустой странице).
3. Перейдите во кладку "ссылки".
4. В ней "оглавление" (в левом углу). Нужно автособираемое оглавление (выбирите любое). Оглавление должно появиться, но обычно, в неправильном оформлении.
5. Делаем оглавление правильным:
- Выделите весь текст оглавления (если щелкните по нему, то оглавление станет темным, но нам нужно именно выделить весь текст оглавления, как это делают для любого текста).
- Измените шрифт на 14 размер и стиль на "TimesNewRoman".
- Перейдите в абзац (если его не видно, еще раз правой кнопкой мыши по выделенному тексту оглавления). Тут проверьте интервал перед и после абзаца 0 пт, междустрочный интервал 1,5. Остальное не меняем.
6. Выделите отдельно сам заголовок "Оглавление". Его сделайте черным цветом, жирным , 14 размер, шрифт "TimesNewRoman", расположите по центру (для редактирование можно выделить и перейти на вкладку "главная").
7. Проверьте, чтобы сам текст оглавления не был никак выделен (не был жирным, подчеркнутым и т.д.).
### Список источников
Со списком источников у всех по разному, у кого-то принимают один вариант, у другого другой, но различия минимальны. Можешь отредактировать их по-своему желанию. Вот как оформить, чтобы точно приняли:
1. Перейдите на [сайт](http://www.snoskainfo.ru/)
   > если вдруг сайт не доступен, поищи в любом браузере "сноска инфо ру"
2. В выплывающем списке выберите нужное (тип источника, если количество авторов не нажимаются, значит не надо), в поле "для чего" - "для списка литературы".
3. Во втором блоке можно всё не заполнять, что-то можно придумать.
4. После нажатия "ок" внизу будет текст с готовым источником. Скопируйте и вставьте в проект, но не забудьте изменить стиль и шрифт текста.
5. Посмотрите, чтобы имена в ссылках были были напечатаны маленькими буквами (только первая заглавная) и на странице не было висячих строк (пример такой строки в низу), если такие есть, то лучше их исправить.
>`_________________`  
>`|   1.блаблабла |`  
>`|блабла         |` <- вот тут  
>`|   2. ...      |`  
>`|               |`
